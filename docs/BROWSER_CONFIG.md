# 浏览器配置说明

## 无头模式配置

在开发测试阶段，你可以通过配置来显示或隐藏浏览器窗口。

### 配置位置

文件：`src/main/resources/application.yml`

```yaml
audit:
  crawler:
    headless: false  # 是否使用无头浏览器
```

### 配置选项

| 配置值 | 说明 | 适用场景 |
|--------|------|---------|
| `false` | **显示浏览器窗口**（有头模式） | 开发测试、调试爬虫行为 |
| `true` | **隐藏浏览器窗口**（无头模式） | 生产环境、自动化测试 |

### 使用建议

#### 🔧 开发/测试环境
```yaml
audit:
  crawler:
    headless: false  # 显示浏览器，方便调试
```

**优点**：
- ✅ 直观看到爬虫过程
- ✅ 便于调试反爬虫策略
- ✅ 可以手动观察页面加载
- ✅ 发现问题更快

**注意**：需要有图形界面环境

#### 🚀 生产环境
```yaml
audit:
  crawler:
    headless: true  # 隐藏浏览器，节省资源
```

**优点**：
- ✅ 节省系统资源
- ✅ 不需要图形界面
- ✅ 适合服务器部署
- ✅ 性能更好

### 配置验证

启动应用后，在日志中查找以下信息：

```
2026-01-28 08:42:49.322 [main] INFO  c.x.a.i.PlaywrightManager - 正在初始化浏览器实例池，目标大小: 3, 无头模式: false
```

- `无头模式: false` = 将会看到浏览器窗口
- `无头模式: true` = 浏览器在后台运行

### 运行时效果

#### headless: false (当前配置)
启动应用后，你会看到：
1. 弹出3个Chromium浏览器窗口
2. 当执行爬虫任务时，可以看到浏览器自动操作
3. 页面加载、点击、输入等行为都清晰可见

#### headless: true
- 应用正常运行，但看不到浏览器窗口
- 所有操作在后台完成
- 适合无图形界面的服务器环境

### 快速切换

无需重启IDE，只需：
1. 修改 `application.yml` 中的 `headless` 值
2. 重新编译并启动应用
   ```bash
   mvn clean package -DskipTests
   java -jar target/xhs-audit-1.0.0-SNAPSHOT.jar
   ```

### 故障排查

如果设置 `headless: false` 但没有看到浏览器：

1. **检查环境**：确保有图形界面（不是SSH终端）
2. **查看日志**：确认配置是否生效
3. **检查权限**：某些系统可能需要特殊权限显示窗口

### 开发技巧

**调试爬虫时的最佳实践**：

```yaml
# 开发配置
audit:
  crawler:
    headless: false       # 显示浏览器
    timeout-seconds: 60   # 增加超时时间，方便观察
    retry-times: 1        # 减少重试，加快调试
```

这样你可以：
- 清楚看到每一步操作
- 观察页面加载时间
- 发现反爬虫拦截点
- 手动测试选择器
